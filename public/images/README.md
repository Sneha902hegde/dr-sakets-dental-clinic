## How to use

1. Copy your photos into the correct folders using the exact filenames above.
2. Tell me which images you've added and I'll wire them into the site instantly.
3. You can do this in batches — replace a few at a time, the rest stay as placeholders.

## Tips

- Use `.jpg` for photos, `.png` for logos or graphics with transparency.
- Recommended sizes: hero images ~1600px wide, gallery tiles ~900px wide.
- Keep file sizes under 300KB per image for fast loading (use https://squoosh.app to compress).
